# Security Policy

## Reporting a Vulnerability

Augur is a local command-line tool. It does not run a network service, and it sends no data anywhere.

If you find a security problem, report it privately by email to nicolasdwidharma@gmail.com with the subject line `augur security`. Please include steps to reproduce and the impact you see. Do not open a public issue for security reports before a fix is available.

You should receive an initial response within 7 days. If the report is accepted, a fix is developed privately and released before public disclosure.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes |

## Scope

In scope: the Augur package, its CLI, and the report generators.
Out of scope: the example dataset, third-party packages (report those upstream).
